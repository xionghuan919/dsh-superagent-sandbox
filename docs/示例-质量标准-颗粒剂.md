# 示例药业 · 质量标准（脱敏样例）

> 虚构示例，仅用于测试。

文件编号：BZ-2026-001
版本：v1.0

## 1. 适用范围

适用于虚构复方颗粒剂（示例）的成品检验。

#### 2. 检验项目与限度

| 检验项目 | 方法 | 限度 |
| --- | --- | --- |
| 性状 | 目视 | 淡黄色颗粒 |
| 水分 | 干燥失重法 | 不得过 3.0% |
| 含量测定 | HPLC | 不得少于 95.0% |
| 溶化性 | 热水溶解 | 应符合规定 |
| 微生物限度 | 药典方法 | 需氧菌总数 ≤ 10^3 cfu/g|

### 3. 检验方法摘要

3.1 水份：取本品 2.0 g，105℃干燥至恒重。
3.2 含测：照高效液相色谱法测定，计算含量。
3.3 溶化性：取本品 10 g，加 80℃热水 200 mL，搅拌 5 分钟。

## 4. 判定规则

全部项目符合规定，判为合格；任一项不符合，判为不合格。
