# 示例药业 · 文件管理 SOP（脱敏样例）

> 虚构示例，仅用于测试。

文件编号：SOP-QA-001
版本：V1.0
页码：1/5

## 1. 目的

规范文件的起草、审核、批准、发放、修订与销毁。

## 2. 范围

适用于本公司所有GMP文件。

#### 3. 职责

3.1 文件管理员：负责文件编号、发放、回收、归挡。
3.2 使用部门：负责本部门文件的起草与执行。
3.3 质量部：负责审核与批准。

## 4. 程序

4.1 文件起草：由使用部门起草，填写《文件起草申请表》。
4.2 文件审核：质量部审核内容的合规性、准确性。
4.3 文件批准：质量负责人批准后生效。
4.4 文件发放：文件管理员按受控范围发放，并做好发放记录。
4.5 文件修订：文件需修订时，重新走起草、审核、批准流程，版本号递增。
4.6 文件销毁：过期文件由文件管理员统一回收、销毁，并记录。

- 《文件起草申请表》
- 《文件发放记录》
- 《文件回收销毁记录》
